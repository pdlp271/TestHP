## 📂 Seamless 3-Step File Indexing

> [!TIP]
> Get your whole library searchable in minutes. Just follow these steps 👇

| Step | Action | What happens |
| :---: | :--- | :--- |
| **1️⃣** | 🔑 **Grant Permissions** | Add your bot as an **Administrator** in your file channel with delete & invite permissions. |
| **2️⃣** | 🤖 **Auto-Discovery** | Any new file posted to the channel is automatically indexed into MongoDB in real-time. |
| **3️⃣** | 📥 **Manual Batch Indexing** | Forward existing files or send post message links directly to the bot in PM. |

## 🚀 Quick Setup & Deployment

<details open>
<summary><b>💻 1. Local Run</b></summary>

```bash
# Clone the repository
git clone https://github.com/DreamXBotz/Auto_Filter_Bot.git
cd Auto_Filter_Bot

# Install dependencies
pip install -r requirements.txt

# Configure environment
cp .env.example .env

# Start the bot
python bot.py
```
</details>

<details>
<summary><b>🐳 2. Docker</b></summary>

```bash
docker build -t auto-filter-bot .
docker run --env-file .env -p 8080:8080 auto-filter-bot
```
</details>

<details>
<summary><b>☁️ 3. Cloud / Render Hosting</b></summary>

1. Fork or push this repository to GitHub.
2. Create a new **Web Service** on [Render](https://render.com).
3. Set Runtime Environment to **Docker** (or Python 3).
4. Add your environment variables and click **Deploy**.

</details>

## ⚙️ Key Environment Variables

| Variable | Required | Description |
| :--- | :---: | :--- |
| `BOT_TOKEN` | ✅ | Telegram Bot Token from [@BotFather](https://t.me/BotFather) |
| `API_ID` | ✅ | Telegram API ID from [my.telegram.org](https://my.telegram.org) |
| `API_HASH` | ✅ | Telegram API Hash from [my.telegram.org](https://my.telegram.org) |
| `ADMINS` | ✅ | Telegram User IDs of administrators (space-separated) |
| `DATABASE_URI` | ✅ | MongoDB connection string |
| `LOG_CHANNEL` | ✅ | Channel ID for activity logs (e.g. `-100...`) |
| `CHANNELS` | ➖ | Channels to auto-index files from (Bot must be admin) |
| `STREAM_MODE` | ➖ | Enable or disable media streaming mode |

> 📘 Refer to [`info.py`](info.py) for all available configuration options.

## 🎮 Essential Commands

### 👥 For Everyone

| Command | Description |
| :--- | :--- |
| `/start` | 🏠 Start the bot & open main menu |
| `/settings` | ⚙️ Open group filter & customize settings |
| `/plan` / `/myplan` | 💎 View pricing or check active premium plan |
| `/redeem <code>` | 🎟️ Redeem a premium voucher code |
| `/id` / `/info` | 🆔 Get user/chat ID and information |
| `/alive` / `/ping` | 🟢 Check bot status & response latency |

### 👑 For Admins

| Command | Description |
| :--- | :--- |
| `/stats` | 📊 View database storage & bot statistics |
| `/broadcast` | 📢 Broadcast a message to all bot users |
| `/grp_broadcast` | 📣 Broadcast a message to all connected groups |
| `/ban` / `/unban` | 🚫 Manage user ban status |
| `/add_premium` | 💎 Grant premium access to a user |
| `/deleteall` | 🗑️ Clear all indexed files from database |
| `/restart` | 🔄 Restart the bot process |
